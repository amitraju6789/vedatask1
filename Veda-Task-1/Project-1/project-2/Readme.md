# Student Grade Calculator

A Java command-line application built for Veda Technologies Internship. It calculates total marks, percentage, and assigns grades based on user input for multiple subjects.

## Features
- Dynamic input for number of subjects and marks
- Input validation (marks between 0 and 100)
- Array storage for subject marks
- Method-based calculation logic
- Automatic grade calculation (A to F)

## How to Run
```bash
javac GradeCalculator.java
java GradeCalculator
