# Command-Line Calculator

A simple Java-based command-line calculator built to perform basic arithmetic operations using user input.

## Features
- **Operations Supported:** Addition, Subtraction, Multiplication, Division, and Modulus.
- **Input Handling:** Validates non-numeric inputs gracefully without crashing.
- **Error Handling:** Handles division and modulus by zero explicitly with informative error messages.
- **Interactive Menu:** Simple loop-based menu interface for continuous calculations.

## Tools & Requirements
- **Language:** Java (JDK 8 or higher)
- **IDE/Editor:** VS Code / IntelliJ IDEA / Eclipse / Terminal

## How to Run

1. Clone or download this repository.
2. Open terminal/command prompt in the project directory.
3. Compile the Java file:
   ```bash
   javac Calculator.java
