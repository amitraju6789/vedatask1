# Day 33: Student Grade Management System (Project Day 3 of 3)

Finalized console-based Java application for academic record management, student rankings, automated grade calculations, and class-level analytics.

## Features
- **Comprehensive CRUD Operations:** Full lifecycle support for student entities, courses, and marks.
- **Automated Grading & Ranking:** Evaluates percentages and sorts student directories in descending order of performance.
- **Class Analytics:** Computes class average percentage, top performers, and academic warnings.
- **Robust Validation:** Safeguards against invalid mark entries outside the 0–100 boundary.

## How to Run
1. Open terminal in workspace root (`Veda-Task-1`).
2. Compile: `javac task33/StudentGradeManagementSystem.java`
3. Execute: `java task33.StudentGradeManagementSystem`
