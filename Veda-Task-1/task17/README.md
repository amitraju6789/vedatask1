# Task 17: Practice ArrayList with an Inventory System

A Java console application demonstrating dynamic collections and full CRUD operations on product records using `java.util.ArrayList`.

## Features
- **Product Domain Model:** Encapsulated class storing `productId`, `name`, `quantity`, and `price`.
- **`ArrayList` Operations:** Dynamic addition, deletion, and element updates.
- **Search Capabilities:** Reusable lookup methods for searching by unique ID or name substring.

## How to Run

1. Open terminal in the root directory (`Veda-Task-1`).
2. Compile the Java source file:
   ```bash
   javac task17/InventorySystemDemo.java
