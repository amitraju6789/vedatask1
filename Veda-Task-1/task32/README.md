# Student Grade Management System

A menu-driven Java application built as part of the Veda Technology Internship Track (Day 32 / Project Day 2 of 3) to manage academic records, subjects, marks, grades, and student performance metrics.

## Key Features
- **Clean OOP Encapsulation:** Modular design separated into `Student`, `Subject`, and `GradeCalculator` domains.
- **Full CRUD Support:** Add, view, search, update, and delete student records dynamically using `ArrayList`.
- **Automatic Evaluation:** Computes total marks, overall percentage, letter grades (A+ to F), and performance remarks automatically.
- **Data Integrity:** Enforces input validation routines on mark entries (range 0–100).
