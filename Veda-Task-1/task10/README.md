# Task 10: Constructor Overloading Demonstration

A Java application demonstrating constructor overloading and constructor chaining using `this()` to flexibly instantiate objects with varied initialization data.

## Features
- **Multiple Constructors:** Supports default, partial, and full parameter initializations.
- **Constructor Chaining (`this()`):** Eliminates redundant assignment code by chaining constructors.
- **Encapsulation:** Uses private fields with clean display mechanisms.

## How to Run

1. Open terminal in the root directory (`Veda-Task-1`).
2. Compile the Java source file:
   ```bash
   javac task10/ConstructorOverloadingDemo.java
   java task10.ConstructorOverloadingDemo
   ```
