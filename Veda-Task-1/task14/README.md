# Task 14: Shape Calculator Using Abstraction

A Java application demonstrating abstraction and inheritance by defining an abstract `Shape` class and specialized geometric implementations (`Circle`, `Rectangle`, and `Triangle`).

## Features
- **Abstract Base Class (`Shape`):** Declares abstract blueprint methods for area and perimeter calculations.
- **Multiple Implementations:** Fully implements `Circle`, `Rectangle`, and `Triangle` geometric formulas.
- **Polymorphic Execution:** Processes diverse shapes uniformly using abstract reference arrays.

## How to Run

1. Open terminal in the root directory (`Veda-Task-1`).
2. Compile the Java source file:
   ```bash
   javac task14/ShapeCalculatorDemo.java
