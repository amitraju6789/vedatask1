# Task 11: Employee Management System (OOP)

A modular, console-based Java application designed using core Object-Oriented Programming principles to manage employee records.

## Features
- **Encapsulated Model (`Employee`):** Keeps sensitive details private with controlled getters and setters.
- **CRUD Operations:** Supports creating new records, searching by unique ID, updating department/salary, and listing all entries.
- **Data Validation:** Enforces unique ID constraints and input type safety.

## How to Run

1. Open terminal in the root directory (`Veda-Task-1`).
2. Compile the Java source file:
   ```bash
   javac task11/EmployeeManagementSystem.java
