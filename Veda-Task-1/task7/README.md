# Task 7: Prime Number Analysis

A Java command-line tool for checking prime numbers and generating primes within a specified range using optimized mathematical algorithms.

## Features
- **Prime Checker:** Tests individual integers for primality using $O(\sqrt{n})$ loop bound optimization.
- **Range Generator:** Finds and displays all prime numbers within user-defined bounds.
- **Edge-Case Handling:** Properly handles numbers less than 2, negative integers, and invalid menu inputs.

## How to Run

1. Open terminal in the root directory (`Veda-Task-1`).
2. Compile the Java source file:
   ```bash
   javac task7/PrimeAnalysis.java
