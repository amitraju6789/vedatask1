# Task 18: Implement HashMap-Based Employee Lookup

A Java console application demonstrating key-value data structures and hashing by implementing a high-performance employee lookup system.

## Features
- **Employee HashMap (`Map<String, Employee>`):** Maps unique employee IDs directly to entity records for instant retrieval.
- **CRUD Operations:** Supports adding records, $O(1)$ ID lookups, detail updates, and record deletions.
- **Unique Key Constraints:** Guards against duplicate employee IDs.

## How to Run

1. Open terminal in the root directory (`Veda-Task-1`).
2. Compile the Java source file:
   ```bash
   javac task18/HashMapEmployeeLookup.java
