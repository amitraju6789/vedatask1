# Multiplication Table Generator

A simple Java-based command-line tool that generates formatted multiplication tables for a single number or a specified range of numbers.

## Features
- **Single Number Table:** Generates a clean 1–10 multiplication table for any input integer.
- **Range-Based Generation:** Generates multiple tables across a user-defined range using nested loops.
- **Formatted Console Output:** Displays output in aligned column format for readability using `printf`.
- **Input Validation:** Gracefully handles invalid inputs.

## Tools & Requirements
- **Language:** Java (JDK 8 or higher)
- **IDE/Editor:** VS Code / IntelliJ IDEA / Eclipse / Terminal

## How to Run

1. Clone or download this repository.
2. Open terminal/command prompt in the `task5` directory.
3. Compile the Java file:
   ```bash
   javac -d . MultiplicationTable.java
   java task5.MultiplicationTable
   ```
