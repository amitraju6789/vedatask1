# Task 12: Employee Inheritance Hierarchy

A Java application demonstrating Object-Oriented Programming inheritance by modeling a base `Employee` class and specialized child classes (`Developer`, `Manager`, and `Intern`).

## Features
- **Base Class (`Employee`):** Shares common fields (`name`, `id`, `baseSalary`) and standard methods.
- **Child Classes:** Specialized subclasses extending parent functionality using the `extends` keyword and `super()` constructor chaining.
- **Method Overriding:** Customizes behavior in subclasses to match specialized roles.

## How to Run

1. Open terminal in the root directory (`Veda-Task-1`).
2. Compile the Java source file:
   ```bash
   javac task12/EmployeeHierarchyDemo.java
   java task12.EmployeeHierarchyDemo
   ```
