# Palindrome Checker

A Java console application that checks whether a given string or number is a palindrome.

## Features
- **String Palindrome Checker:** Case-insensitive check using two-pointer character comparison.
- **Number Palindrome Checker:** Validates integers using mathematical modulo-reversal logic.
- **Robust Parsing:** Strips whitespace and special characters from text inputs.

## How to Run

1. Open terminal in the root repository directory (`Veda-Task-1`).
2. Compile the Java file:
   ```bash
   javac task6/PalindromeChecker.java
