# Task 20: Customer Support Queue System

A Java application implementing a First-In-First-Out (FIFO) customer support ticket processor using `java.util.Queue` and `java.util.ArrayDeque`.

## Features
- **FIFO Processing:** Ensures incoming customer issues are resolved in exact arrival sequence.
- **`ArrayDeque` Implementation:** Provides high-performance resizable array-backed queue operations without memory allocation overhead.
- **Queue Operations:** Enqueue (`offer`), Dequeue (`poll`), Peek (`peek`), and iteration.

1. Open terminal in the root directory (`Veda-Task-1`).
2. Compile the Java source file:
