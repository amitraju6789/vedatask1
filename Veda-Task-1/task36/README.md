# Veda Technology Business & Service Management System (Day 36)

Second phase of the Veda Technology major project track, expanding core architecture to manage internship programs, advanced service categories, customer inquiries, and robust reporting pipelines.

## Key Features
- **Extended OOP Hierarchy:** Added `InternshipProgram` extending the abstract `Offering` base class.
- **Advanced Filtering & Search:** Multi-criteria keyword and category search routines across services, training, and internships.
- **Lifecycle Request Tracking:** Manages pending, in-progress, and completed service/internship requests.
- **Executive Reporting:** Computes operational metrics and request statuses.

## How to Compile & Run
1. Open terminal in workspace root (`Veda-Task-1`).
2. Compile: `javac task36/VedaBusinessManagementSystem.java`
3. Execute: `java task36.VedaBusinessManagementSystem`
