# Number Guessing Game

A simple Java-based command-line game where the application generates a random number and the user attempts to guess it.

## Features
- **Random Generation:** Generates a random target number dynamically using Java's `Random` class.
- **Interactive Hints:** Provides immediate "Too high" or "Too low" feedback for every guess.
- **Attempt Tracking:** Keeps track of the total number of attempts taken to guess the correct number.
- **Input Validation:** Prevents application crashes by gracefully handling non-numeric inputs.

## Tools & Requirements
- **Language:** Java (JDK 8 or higher)
- **IDE/Editor:** VS Code / IntelliJ IDEA / Eclipse / Terminal

## How to Run

1. Clone or download this repository.
2. Open terminal/command prompt in the project directory.
3. Compile the Java file:
   ```bash
   javac NumberGuessingGame.java
